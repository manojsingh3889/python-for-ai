install package</br>
<code>pip install package-name</code></br>
<code>pip install package-name==version</code>

import module in code

<code>import module-name </code> whole module </br>
<code>from module import function</code> comma seperated list of functions</br>
<code>import module as alias</code></br>

freeze requirement from terminal</br>
<code> pip freeze > requirements.txt</code></br>
install requirement from requirements.txt</br>
<code> pip install -r requirements.txt</code></br>

<setting> vscode://settings/python.terminal.executeInFileDir</setting>
